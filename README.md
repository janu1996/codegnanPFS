# ATM Application – Python OOP

A simple ATM application developed using Python and Object-Oriented Programming concepts.

### Features
- 4-digit PIN validation
- Login with limited attempts
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Exit safely from the application

### Concepts Used
- Classes and Objects
- Constructor
- Instance Variables
- Methods
- Conditional Statements
- Loops
- Lists
- User Input
- Basic Exception/Validation Logic
